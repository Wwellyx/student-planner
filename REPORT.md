### 6. Разрешение конфликта

Конфликт возник из-за того, что в двух разных ветках
была изменена одна и та же строка файла tasks.md.

В ветке main задача была изменена на
«Подготовить презентацию по информатике».

В ветке feature/new-features задача была изменена на
«Подготовить отчёт по практике».

При попытке слияния Git обнаружил конфликт.

Для его разрешения файл tasks.md был открыт вручную.
Была выбрана одна согласованная версия задачи,
после чего удалены все маркеры конфликта.

Разрешение конфликта зафиксировано отдельным коммитом.

### 7. Проверка репозитория

Для проверки использовались команды:

- git fetch

- git log --oneline --graph --all

ветке main. Рабочая директория не содержит
незафиксированных изменений.
