# Student Planner

Планировщик учебных задач для студентов.
Помогает организовывать учебный процесс и контролировать выполнение заданий.

## Возможности
- Добавление учебных задач
- Просмотр списка задач
- Отслеживание выполнения заданий

## Версия проекта
1.0

## Целевая аудитория

Проект предназначен для студентов колледжей и вузов, которым необходимо организовать учебные задачи. 

## Принципы использования

- Ргулярное добавление новых задач
- Указание сроков выполнения
- Контроль выполненных заданий
- Рассортировка приоритетов
